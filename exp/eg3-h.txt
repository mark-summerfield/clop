usage: str SUBCOMMAND [OPTIONS] …

Stores generational copies of specified files (excluding those
explicitly ignored) in .dirname.str. (For a GUI run
store.)

SUBCOMMANDS:
s or status       Status reports any unstored unignored nonempty files
                  and whether updates or cleaning are needed. [Default
                  action for str with no arguments.]
  suboptions:
    -v or --verbose  Show the name of every new/changed file [default
                     just show counts].
    -h or --help     Show status help and quit.
u or update       Updates all the files in the store by creating a new
                  generation and storing all those that have changed.
  positionals: [TAG]
                  For the TAG use quotes if multiple words.
  suboptions:
    -v or --verbose  Show the name of every updated file [default just
                     show counts].
    -h or --help     Show update help and quit.
a or add          Add the given files and the files in the given folders
                  to the store. If none given then adds the files in the
                  current folder and its immediate subfolders, except
                  for those ignored or empty, creating the store if
                  necessary.
  positionals: [FILE1 [FILE2 … [FILEn]]]
                  The given files and folders to add.
  suboptions:
    -v or --verbose  Show the name of every added file [default just
                     show counts].
    -h or --help     Show add help and quit.
e or extract      Extract the given filenames at the generation, e.g.,
                  filename.ext will be extracted as
                  filename@gid.ext, etc.
  positionals: [@GID] <FILE1> … <FILEn>
                  @GID is the generation to extract [default current];
                  FILE1 … FILEn are the files to extract.
  suboptions:
    -v or --verbose  Show the name of every extractd file [default
                     just show counts].
    -h or --help     Show extract help and quit.
p or print        Print the given file from the store at the given (or
                  current if not specified) generation. (Should only be
                  used for plain text files!).
  positionals: [@GID] <FILE>
                  @GID is the generation to print from [default current];
                  FILE is the file to print.
  suboptions:
    -h or --help  Show print help and quit.
c or copy         Copy all the files at the given or current generation
                  into the given folder (which must not exist).
  positionals: [@GID] <FOLDER>
                  @GID is the generation to copy from [default current];
                  FOLDER is the folder to create and copy into.
  suboptions:
    -v or --verbose  Show the name of every copied file.
    -h or --help     Show copy help and quit.
d or diff         Diff the filename at @GID1 against the one in the
                  current folder, or against the one stored at
                  @GID2 if given; shows the entire file, unless
                  quiet is specified when only differences and context
                  lines are shown.
  positionals: <@GID1> [@GID2] <FILE>
                  @GID1 is the first generation; @GID2 is the second
                  generation [default current]; FILE is the file to diff at
                  these generations.
  suboptions:
    -q or --quiet  Show the differences and some context only [default
                   show the whole file].
    -h or --help   Show diff help and quit.
f or filenames    List the tracked files.
  positionals: [@GID]
                  @GID is the generation to list [default current].
  suboptions:
    -h or --help  Show filenames help and quit.
g or generations  Print the generations (and all their filenames if
                  --full).
  suboptions:
    -f or --full  Show filenames.
    -h or --help  Show generations help and quit.
G or gui          Start the gui.
  suboptions:
    -h or --help  Show gui help and quit.
H or history      Print the given file’s history.
  positionals: <FILE>
                  The file to print the history of.
  suboptions:
    -h or --help  Show history help and quit.
i or ignore       Add the given filenames, folders, and globs to the
                  ignore list.
  positionals: <ITEM1> [ITEM2 … [ITEMn]]
                  Each ITEM is a file or a folder or a glob pattern.
  suboptions:
    -h or --help  Show ignore help and quit.
I or ignores      Print the ignore list.
  suboptions:
    -h or --help  Show ignores help and quit.
U or unignore     Remove the given filenames, folders, and globs from
                  the ignore list.
  positionals: <ITEM1> [ITEM2 … [ITEMn]]
                  Each ITEM is a file or a folder or a glob pattern.
  suboptions:
    -h or --help  Show unignore help and quit.
t or tag          Set the tag for the current or given generation to the
                  given tag.
  positionals: <@GID> <TAG>
                  @GID is the generation to tag [default current]. For the
                  TAG use quotes if multiple words.
  suboptions:
    -h or --help  Show tag help and quit.
untag             Untag the current or given generation.
  positionals: [GID]
                  @GID is the generation to untag [default current].
  suboptions:
    -h or --help  Show untag help and quit.
T or untracked    Print any untracked files.
  suboptions:
    -h or --help  Show untracked help and quit.
restore           Restore the specified files by overwriting those
                  on disk with those from the store.
  positionals: <FILE1> [FILE2 … [FILEn]]
                  The files to restore.
  suboptions:
    -h or --help  Show restore help and quit.
C or clean        Cleans the store by deleting empty generations, i.e.,
                  those without any changes.
  suboptions:
    -h or --help  Show clean help and quit.
purge             Purge the given file from the store by deleting every
                  copy of it at every generation.
  positionals: <FILE>
                  The file to purge from the store.
  suboptions:
    -h or --help  Show purge help and quit.
h or help         Full help.


OPTIONS:
  -v or --version  Show version and quit.
  -h or --help     Show this help and quit. Use h or help for
                   full help.

@GID — @-prefixed generation number or tag name, (e.g., @28,
@alpha1); if unspecified, the current generation is assumed.
GLOB — when using globs for ignore or unignore use quotes to avoid
shell expansion of glob characters (e.g., '*.o'). Subcommands that
print output to stdour unless redirected by the shell. For help on a
specific subcommand follow the subcommand with -h or --help or
just use h or help for full help.
